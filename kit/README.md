# The panel kit

One look and one set of gestures for every plug-in in the range: same ink, type and
grid on a different paper stock. A plug-in supplies a `kit::Stock` and gets the knob,
keys, fields, panels, masthead, readout, preset browser and the Bench.

The same copy of this folder lives in each plug-in's repository until the range has a
name and a repository of its own. Change it in one, then copy it to the others.

VT323 and Press Start 2P are under the SIL Open Font License (`fonts/`).
