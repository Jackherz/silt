# Audit and roadmap: where each item stands

Working through the external "bug audit, improvement review and product roadmap"
of 27 October 2026, item by item. That review read an out-of-date README, so several
of its gaps (Slice mode, presets, help) were already built; those are marked as such.
The README is now current.

Status: **done** (this pass, with its commit), **already** (built before the
review), **blocked** (needs something this machine doesn't have), **open** (worth
doing, not started), **decide** (a product call for the owner first).

## Reliability (the review's P0)

| Item | Status | Notes |
|---|---|---|
| 1. State restore: empty, garbage, truncated, foreign, corrupt FLAC | done `fb87be7` | Tests for each. Corrupt lengths can't ask for more than the state holds; a bad FLAC keeps the sample there was. |
| 1. Hostile sample headers (rate, channels, length) | done `fb87be7` | `decode` refuses rates outside 1–768 kHz, reads at most two channels, never sizes a buffer from a bad header. |
| 1. Restore while audio runs | done `fb87be7` | Test restores 20 times while another thread runs `processBlock`. |
| 1. Mono, 44.1 kHz, 24-bit samples round-trip with the set | done `fb87be7` | |

| 2. Repeated prepare / sample-rate change / bus changes | already | pluginval strictness 10 (both builds) exercises these; passes. |
| 3. Capture and live-ring boundaries | already | Existing capture, FEED and fuzz tests; pluginval. |

| 4. All-notes-off ordering, repeats, channels, bursts | done `f9d7d0b` | All-notes-off ends earlier notes in the same block and anything sustained. Omni (any channel), documented. |
| 4. Pitch bend as pitch | decide | Today pitch bend is a MIDI modulator source. A fixed bend range is easy if wanted. |
| 5. Automation semantics, base vs heard values | already | `review-2026-10-25` F1–F14; rings show modulation on knobs. |
| 6. AU validation | done | `auval` passes both (`aumu Slti`, `aumf Sltf`), 27 Oct. |
| 6. VST3 validation | done | pluginval 10 + hostcheck pass both builds, 27 Oct. |
| 6. CLAP in Reaper/Bitwig, AU in Logic | blocked | No such hosts here; needs the owner or a tester. |
| 6. Windows / Linux builds and CI | blocked | Windows parked by the owner; GitHub Actions minutes run out until 1 Nov. |
| 7. CPU budget and benchmarks | done | `silt-plugin-tests "[benchmark]"`. The worst case (16 notes, densest grains, every effect, per-voice modulation) took 74–96% of a core at 48 kHz and 160–171% at 96 kHz: past real time. Fixed with an engine-wide grain budget (384 grains at 48 kHz, scaled with the rate, shared by the voices playing; per-voice modulation had been bypassing the cap) and a faster sample read: now 24–25% at 48 kHz, 30–32% at 96 kHz. Typical settings: about 1.5%. |
| 8. Sample import limits and failures | done `afaf4ef` | Formats and limits in the README; files past 30 s say they were trimmed; the screen shows length, rate, mono/stereo and memory. |
| 9. Screen readers | done | Every control has a title (its label) and a description (its hover help); panel parts too. |
| 9. Keyboard navigation, touch | open | Keys 1–4 arm modulators, Esc, Cmd/Ctrl+Z; full tab-through navigation not yet. Mod colours always carry a number and dash pattern too. |
| 10. Undo semantics | done `4b30cc0` | Preset loads are one undo step (they used to wipe the history); UNDO's tooltip and help say what is and isn't covered. |
